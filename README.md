# Эволюция — онлайн

Веб-игра на основе настольной «Эволюции»: колода из 84 карт свойств
(включая двусторонние), стол с перетаскиванием карт, мультиплеер по
коду комнаты. Работает как обычный сайт и как Telegram Mini App.

## Структура проекта

Код разбит на небольшие ES-модули (`import`/`export`), каждый файл
отвечает за одну вещь. Полное описание — в
[ARCHITECTURE.md](./ARCHITECTURE.md). Коротко:

```
index.html            — разметка, точка входа <script type="module" src="js/main.js">
css/01…12-*.css         — стили, разбитые по экранам/блокам интерфейса
js/data/cards.js          — КАРТЫ И ИХ ТЕКСТЫ. Правите баланс/описания — сюда.
js/data/deck.js             — сборка и тасовка колоды
js/data/phases.js             — стадии хода
js/config.js                    — сюда вставляете свои ключи Firebase (см. ниже)
js/storage/                       — доступ к "серверу" комнаты (Firebase / тест / офлайн)
js/telegram.js                      — интеграция с Telegram Mini Apps
js/drag/                              — перетаскивание карт пальцем/мышью
js/catalog/                             — вкладка "Каталог карт"
js/lobby/                                 — создание/вход в комнату
js/board/                                   — сам игровой стол
js/main.js                                    — точка входа, склеивает всё вместе
```

Хотите поменять текст карты или добавить новую — открываете только
`js/data/cards.js`. Хотите поменять цвета — `css/01-tokens.css`.
Что открывать для других правок — см. таблицу в ARCHITECTURE.md.

## Как играть

1. Один игрок жмёт «Создать комнату», получает код из 4 символов.
2. Остальные жмут «Присоединиться», вводят этот код и своё имя.
3. Когда все в сборе — любой жмёт «Начать игру»: колода тасуется,
   каждому раздаётся по 6 карт.
4. Карту из руки можно перетащить:
   - на стол игрока (пустое место в его ряду) — карта ляжет
     рубашкой вверх как новый вид;
   - на уже выложенный вид (свой или чужой) — карта прикрепится к
     нему как свойство;
   - в свой сброс — карта уйдёт в отбой.
5. Карту из колоды можно перетащить в свою руку — или просто
   кликнуть по колоде.
6. У двусторонних карт (например, «Паразит / Хищник») в углу есть
   значок ⟲ — нажмите, чтобы выбрать, какой стороной играть.
7. Стадии хода и кормовая база — общие индикаторы для всех, ими
   управляет любой игрок вручную; сама игра правила не проверяет.
