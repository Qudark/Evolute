# Эволюция — онлайн

Веб-игра на основе настольной «Эволюции»: колода из 84 карт свойств
(включая двусторонние), стол с перетаскиванием карт, мультиплеер по
коду комнаты. Работает как обычный сайт и как Telegram Mini App.

## Структура проекта

```
index.html          — разметка, ничего игрового тут нет
css/style.css        — весь визуал
js/data.js            — КАРТЫ И ИХ ТЕКСТЫ. Правите баланс/описания — сюда.
js/config.js           — сюда вставляете свои ключи Firebase (см. ниже)
js/storage.js            — доступ к "серверу" комнаты (Firebase / тест / офлайн)
js/telegram.js             — интеграция с Telegram Mini Apps
js/dragdrop.js               — перетаскивание карт пальцем/мышью
js/catalog.js                 — вкладка "Каталог карт"
js/lobby.js                    — создание/вход в комнату
js/board.js                     — сам игровой стол
js/main.js                       — точка входа, склеивает всё вместе
```

Хотите поменять текст карты или добавить новую — открываете только
`js/data.js`. Хотите поменять цвета — только `css/style.css`. Другие
файлы трогать не нужно.

## Важно: без хостинга это НЕ будет работать между разными телефонами

Пока вы просто открываете `index.html` двойным кликом у себя на
компьютере, страница видит только сама себя — второй игрок с другого
телефона к ней не подключится. Чтобы играть с друзьями, нужны два
бесплатных шага:

### Шаг 1 — бесплатный хостинг (GitHub Pages)

1. Зарегистрируйтесь на [github.com](https://github.com) (бесплатно).
2. Создайте новый репозиторий, например `evolution-game`.
3. Загрузите туда все файлы этой папки (кнопка "Add file → Upload
   files" в интерфейсе GitHub, можно перетащить всю папку).
4. Settings → Pages → Source: выберите ветку `main` → Save.
5. Через минуту GitHub покажет ссылку вида
   `https://ваш-логин.github.io/evolution-game/` — это и есть ваш
   работающий сайт, бесплатно и навсегда.

*(Подойдёт и любой другой бесплатный статический хостинг — Netlify,
Vercel, Cloudflare Pages — процесс аналогичный: залить папку целиком.)*

### Шаг 2 — бесплатная синхронизация между устройствами (Firebase)

Без этого шага игра будет работать только на одном устройстве за раз.

1. [console.firebase.google.com](https://console.firebase.google.com)
   → Add project → любое имя → создать (карта не требуется).
2. В проекте: Build → Realtime Database → Create Database → любой
   регион → **Start in test mode**.
3. Шестерёнка рядом с "Project Overview" → Project settings → вкладка
   General → в самом низу "Your apps" → нажать значок `</>` (Web) →
   зарегистрировать (имя любое, Hosting не подключать) → скопировать
   объект `firebaseConfig`.
4. Вставьте его в `js/config.js` вместо пустого объекта:

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "your-project.firebaseapp.com",
  databaseURL: "https://your-project-default-rtdb.firebaseio.com",
  projectId: "your-project",
  storageBucket: "your-project.appspot.com",
  messagingSenderId: "...",
  appId: "..."
};
```

5. Загрузите обновлённый `js/config.js` обратно в GitHub (тем же
   способом, что и в шаге 1) — сайт обновится сам.

Тестовый режим Realtime Database открыт для чтения/записи всем, у
кого есть ссылка на проект, и действует 30 дней — этого более чем
достаточно для игры с друзьями. Если нужно дольше, в разделе Rules
можно продлить срок или упростить правила вручную.

> Пока `js/config.js` пустой, игра сама переключится в офлайн-режим
> (одно устройство) — так тоже можно проверить интерфейс и
> перетаскивание карт, просто без реального мультиплеера. Внутри
> **этого чата с Claude** игра дополнительно умеет работать через
> встроенное хранилище Claude — это только для быстрого теста прямо
> тут и не переживёт выхода за пределы чата.

## Шаг 3 (необязательно) — открыть как Telegram Mini App

1. В Telegram напишите [@BotFather](https://t.me/BotFather) →
   `/newbot` → придумайте имя и юзернейм — получите бесплатного бота.
2. `/mybots` → выберите бота → Bot Settings → Menu Button →
   Configure Menu Button → вставьте ссылку на ваш сайт с шага 1
   (`https://ваш-логин.github.io/evolution-game/`).
3. Всё — теперь у бота внизу чата появится кнопка, открывающая игру
   прямо внутри Telegram, на телефоне и на компьютере. Полностью
   бесплатно, без сервера с вашей стороны.

## Как играть

1. Один игрок жмёт «Создать комнату», получает код из 4 символов.
2. Остальные жмут «Присоединиться», вводят этот код и своё имя.
3. Когда все в сборе — любой жмёт «Начать игру»: колода тасуется,
   каждому раздаётся по 6 карт.
4. Карту из руки можно перетащить:
   - на стол игрока (пустое место в его ряду) — карта ляжет
     рубашкой вверх как новый вид;
   - на уже выложенный вид (свой или чужой) — карта прикрепится к
     нему как свойство;
   - в свой сброс — карта уйдёт в отбой.
5. Карту из колоды можно перетащить в свою руку — или просто
   кликнуть по колоде.
6. У двусторонних карт (например, «Паразит / Хищник») в углу есть
   значок ⟲ — нажмите, чтобы выбрать, какой стороной играть.
7. Стадии хода и кормовая база — общие индикаторы для всех, ими
   управляет любой игрок вручную; сама игра правила не проверяет.
